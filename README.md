### ฟีเจอร์หลัก (Features)
- ⚡ **โหมดกรอกยอดเหรียญ 2 รูปแบบ:**
  - **โหมด M (ล้าน):** 1 = 1,000,000 เหรียญ (เช่น 90 = 90M) พร้อมปุ่มลัด +1M, +5M, +10M...
  - **โหมดเหรียญตรงตัว / ตัดเศษ (Exact Coins):** พิมพ์เลขตรงตัว เช่น `5205300` หรือ `90000000` พร้อมปุ่มลัด +100K, +500K, +1M... และระบบตัดลูกน้ำ (Comma) อัตโนมัติเมื่อวาง
- 🛡️ **สลับผู้รับภาระภาษี:** พ่อค้าออกภาษีให้ (ลูกค้ารับเต็ม) หรือ ลูกค้าออกภาษีเอง
- 📊 **2 สูตรคำนวณมาตรฐาน:**
  - **POPULAR +2%:** สูตรมาตรฐานพ่อค้า โอนตามยอดบวก 2% (เช่น 10M โอน 10.2M)
  - **EXACT NET 100%:** สูตรสุทธิเป๊ะ (หาร 0.98) ลูกค้าได้รับครบถ้วนไม่มีขาดเศษ
- 💵 **ระบบคิดเงินลูกค้า & เรทราคาตามใจชอบ:** กำหนดราคาต่อ 1M ได้อิสระ (PHP / THB / IDR / USD)
- 📋 **ระบบก็อปปี้บิลในคลิกเดียว:** ออกบิลแชททั้งภาษาไทยและภาษาอังกฤษ (Invoice) สำหรับส่งลูกค้าต่างชาติ
- 💱 **เครื่องแปลงค่าเงินสด 2 ทาง (Live Converter):** ดึงเรทแลกเปลี่ยนจริงแบบเรียลไทม์
- 🌓 **ระบบ 2 ธีม:** Obsidian Gold (Dark Mode) & Ivory Private Bank (Light Mode)
- 🔔 **เสียงสังเคราะห์ Web Audio API:** มีเสียง Chime เมื่อคัดลอกหรือสลับโหมด (เปิด/ปิดได้)
